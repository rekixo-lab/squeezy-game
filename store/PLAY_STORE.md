### ⚠️ Name risk
"Squeezy Girl" and similar "Squeezy …" games already exist on Play. A name that looks like another app can be rejected under the **Impersonation / Intellectual Property** policy, and it also makes the game hard to find. Pick a name that is clearly your own, for example **"Juicy Butt Smash"**, **"Fatty Jump & Squish"** or **"Splash Smash Man"**. Search Play first to make sure your choice is not taken. Once you decide, change it in three places: `project.godot` (config/name), `export_presets.cfg` (package/name) and this listing.

## 5. Testing track ⚠️ (very important for a new personal account)

Personal Play developer accounts created after 13 Nov 2023 must run a **closed test with at least 12 testers who stay opted in for 14 days in a row** before "Production" unlocks.

1. Testing → Closed testing → Create track → upload `build/squeezy_game.aab`
2. Add at least 12 tester Gmail addresses (a Google Group is easiest) and share the opt-in link
3. After 14 days → Dashboard → "Apply for production access" → answer the questions
4. Then promote the same build to Production

(If your developer account is an **Organization** account, this rule does not apply, and you can go straight to Internal testing → Production.)

## 6. Technical facts (already set in the project)

- Format: Android App Bundle (.aab), signed with your **upload key**, with **Play App Signing** turned on (Play's default)
- targetSdk 36 (Android 16), the requirement for new apps and updates from 31 Aug 2026 · minSdk 24
- Architectures: arm64-v8a + armeabi-v7a
- Permissions (all from the Google Mobile Ads SDK, all install-time/normal, no runtime prompts): INTERNET, ACCESS_NETWORK_STATE, AD_ID (+ com.google.android.gms.permission.AD_ID), READ_BASIC_PHONE_STATE, WAKE_LOCK, FOREGROUND_SERVICE, and androidx's own DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION. Gameplay itself is fully offline.
- AdMob: App ID `ca-app-pub-9987799703505828~4755476455`, interstitial `level_complete` = `ca-app-pub-9987799703505828/4508064440` (release builds only; debug builds use Google test IDs). ⚠️ AdMob → Blocking controls → **Content** → **Maximum ad content rating: PG** (the code also sets PG).
- versionCode 2 / versionName 1.0.1. **Every new upload needs a higher versionCode** (in `export_presets.cfg`).
- Upload file: `bash tools/build_release.sh` writes exactly ONE file to `build/upload/squeezy_game_v<name>_code<code>.aab`; logs, manifest and test .apks go to `build/test/`.
- In-app privacy policy: Settings → "Privacy Policy" (always visible, opens the URL above in the browser). "Privacy options" (UMP) is shown only where UMP says it is required.
